# DINESH — Cybersecurity & Web Developer Portfolio

A responsive, multi-page portfolio that retains the original black/cinematic layout and navigation, with cybersecurity motion design, improved project visuals and local assets. Built with HTML, CSS, JavaScript and Vite.

## Pages
- `index.html` — profile, tracks, selected projects, cyber missions, experience, credentials and contact
- `full-stack.html` — full-stack project gallery
- `cyber.html` — cybersecurity projects and reports
- `hardware.html` — AeroRescue Nexus hardware project

## Run locally
1. Install Node.js LTS.
2. Run `npm install`.
3. Run `npm run dev`.
4. Create a production build with `npm run build`.

## Deploy
Deploy the repository to Vercel, Netlify or another static host. Build command: `npm run build`; output directory: `dist`.

## Asset notes
All supplied profile, project, report, certificate and lab-evidence files are stored locally under `public/assets`. Missing project artwork is covered by original local SVG thumbnail illustrations; no hotlinked third-party image URLs are required.
